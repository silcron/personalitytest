# Personality Test

Flutter로 만든 간단한 성격 검사 애플리케이션입니다. 사용자가 검사 항목을 선택하고 답변을 고르면 결과를 확인할 수 있습니다.

## 주요 기능

- 성격 검사 목록 조회
- 검사 문항과 선택지 표시
- 선택한 답변에 따른 결과 화면 제공
- 검사 시작과 답변 선택 이벤트 기록(Firebase Analytics)

## 사용 흐름

`검사 목록 선택 → 문항 및 답변 선택 → 성격 결과 확인`

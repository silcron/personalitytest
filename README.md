# Personality Test

**모바일프로그래밍 수업 프로젝트**로 개발한 Flutter 기반 성격 검사 애플리케이션입니다. 사용자가 원하는 검사를 선택하고 문항에 답하면, 선택 결과에 맞는 성격 결과를 확인할 수 있도록 구현했습니다.

## 프로젝트 목표

- Flutter의 화면 구성과 상태 관리를 활용해 모바일 애플리케이션의 기본 흐름을 구현합니다.
- JSON 형식의 검사 데이터를 앱에서 불러와 화면에 동적으로 표시합니다.
- Firebase Analytics를 연동해 사용자의 검사 선택 및 답변 선택 흐름을 기록합니다.

## 기술 구성

| 구분 | 적용 내용 |
| --- | --- |
| Framework | Flutter / Dart |
| UI 구성 | Material Design, ListView, Radio 버튼, 화면 전환(Navigator) |
| 데이터 | 검사 목록·문항·결과를 JSON 파일로 분리하여 관리 |
| 분석 | Firebase Core 및 Firebase Analytics |
| 지원 환경 | Android, iOS |

## 주요 기능

1. **성격 검사 목록 조회**: 앱 시작 화면에서 제공되는 검사 항목을 목록으로 확인합니다.
2. **문항 및 선택지 표시**: 선택한 검사에 맞는 JSON 데이터를 불러와 질문과 선택지를 표시합니다.
3. **답변 선택 및 결과 확인**: 답변을 고른 뒤 `성격보기` 버튼을 누르면 해당 결과 화면으로 이동합니다.
4. **사용 흐름 기록**: 검사 항목을 선택한 시점과 답변을 선택한 시점에 Analytics 이벤트를 기록합니다.
5. **안정적인 화면 처리**: 데이터 로딩 중에는 진행 표시기를 제공하고, 오류가 발생하면 오류 내용을 화면에 표시합니다.
